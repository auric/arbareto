# Security policy

## Supported versions

Arbareto has no release yet. Only the `main` branch gets security fixes until the first release.

## Report a vulnerability

- Report a vulnerability privately through GitHub private vulnerability reporting. Open the Security tab of this repository, and click "Report a vulnerability".
- Do not open a public issue, discussion, or pull request for a vulnerability.
- Give the commit, the Windows version, the Git version, and the steps that show the problem.
- Remove private paths, user names, and tokens from logs before you attach them.
