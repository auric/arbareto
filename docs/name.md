# The name Arbareto

Arbareto (say "ar-buh-RET-oh") is the Esperanto word for a grove, a small forest.

| Part | Meaning |
|---|---|
| `arb-` | tree |
| `-ar-` | a group (`arbaro` = forest) |
| `-et-` | small |
| `-o` | noun ending |

A Git repository grows like a grove: one trunk and many branches. Arbareto is a calm, compact place to work with them.

Esperanto is no country's national language, so the name is neutral for users everywhere.
